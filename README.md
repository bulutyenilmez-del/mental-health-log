# Mental Health Log

A structured, observation-first log for documenting mental-health experiences over time.

> **Privacy notice:** This repository is public. GitHub Issues, comments, commit history, and files may be visible to anyone and may be copied or archived. Do not publish identifying details, private medical documents, exact locations, information about other people, or details of self-harm plans here. Consider making the repository private before recording personal health information.

## Purpose

- Record experiences in neutral, descriptive language.
- Track changes over time without self-diagnosing.
- Keep observations that may be useful to discuss with a qualified clinician.
- Separate what happened from interpretations about why it happened.

This repository is a personal record, not a diagnostic tool or a substitute for professional care.
